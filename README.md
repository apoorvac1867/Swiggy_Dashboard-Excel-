# Swiggy Sales Dashboard (Excel)

## Project Overview

This project presents an interactive Swiggy Sales Dashboard developed using Microsoft Excel to analyse sales performance, customer ratings, order trends, and restaurant performance.
The dashboard transforms raw sales data into meaningful business insights through interactive visualisations, KPI cards, Pivot Tables, and slicers, helping understand business performance and support data-driven decision-making.

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Maps
- Conditional Formatting
- Excel Formulas

---

## 📊 Dashboard Features

### KPI Cards

- Total Revenue
- Total Orders

- Average Rating

- Average Delivery Time

### Interactive Filters

- Month
- Food Type
- State
- Category

### Visualizations

- State-wise Sales Map
- Monthly Sales Trend
- Day-wise Sales Trend
- Top 10 Restaurants
- Top 5 Cities
- Quarter-wise Sales Summary
- Food Type Distribution

---

## Business Insights

- Generated total sales of **₹53M+** across **197K+ orders**.
- Achieved an average customer rating of **4.34**, reflecting positive customer feedback.
- Bengaluru recorded the highest sales among all cities.
- Sales trends revealed variations across different months and weekdays.
- Vegetarian food contributed a larger share of sales compared to Non-Vegetarian items.
